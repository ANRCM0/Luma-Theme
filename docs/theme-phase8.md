# vv-theme 第八阶段：主题细节与安全打磨（v0.9.0）

本阶段依照产品边界，仅修改 vv-theme 的浏览器侧代码、样式和测试；**跳过原第七阶段主题管理框架的配置预览／备份／迁移工作**。无 TXBoard 后端改动，不增加任何主题配置字段。

## 安全加固

1. **外部支付及服务条款链接**：仅接受经 URL 解析且无内嵌用户名／密码的 HTTPS 地址。仅当当前主题本身运行在 localhost 时允许 HTTP 回环开发链接；拒绝 `javascript:`、`data:`、协议相对链接、恶意转义和不安全外部 HTTP。无法验证的服务条款地址不再渲染假的 `#` 链接。
2. **图片和背景地址**：公告图片、站点 Logo、登录背景仅允许安全的同源相对路径或 HTTPS 资源；禁止远程不加密 HTTP。站点 Logo 和公告图片使用 `referrerPolicy="no-referrer"`，避免将含查询参数的页面 URL 发送给第三方图片域名。公告正文仍以纯文本显示，不插入 HTML。
3. **一次性快捷登录**：登录路由中的 `verify` 参数在组件初始化时立刻从浏览器地址栏删除，但保留本次内部 token 交换所需的内存值及其他有效参数。不要将一次性凭证复制到登录后的分享链接。
4. **账户切换隔离**：登录引导、订阅数据加载、订单／工单加载及手动订阅刷新均在写入 React 状态前核对当前登录令牌和会话代数；用户退出登录后，旧账号的迟到请求不能重新填入新账号视图。旧会话的迟到 401 响应也不应注销之后登录的新账号。
5. **退出登录敏感状态清理**：退出登录时同时清空订阅、公告、工单、账户余额／邀请、当前订单、支付二维码及输入的密码，不只跳转页面。

注意：主题依然沿用 TXBoard 当前的浏览器授权令牌存储方案，**并未宣称解决所有 XSS 或第三方脚本风险**。完整的 CSP、Cookie、反向代理安全头、服务端鉴权与网关审计属于 TXBoard 部署和后端职责，不能仅通过主题代码替代。

## 交互与无障碍细节

- 所有主题弹窗支持 Tab/Shift+Tab 限制焦点在当前最上层弹窗，按 Escape 关闭，关闭后恢复之前的键盘焦点。
- 弹窗开启时锁定页面滚动；二维码弹窗覆盖订单弹窗时不会抢夺键盘焦点。
- 顶部增加键盘可见的「跳转到主要内容」入口，不采用可能触发 SPA 路由跳转的普通 `#` 链接。
- 为按钮、链接、表单输入等添加明显的 `:focus-visible` 样式；错误消息的关闭操作具有明确的无障碍标签。
- 移动端弹窗限制在动态 viewport 可视高度内，并可滚动；尊重系统的 `prefers-reduced-motion` 减少动画偏好。
- 切换二维码数据时先清空旧图片，避免新图生成时显示前一张订阅或支付二维码。

## 验收与部署

CI 继续只使用 Node.js 22：单元测试、产物构建、Playwright 普通模式与模拟真实 API 主题模式全部保留。新增测试验证危险链接拦截、浏览器 URL 凭证清理、跨登录迟到 401、弹窗键盘焦点和不安全公告图片。

预发验收应额外检查：HTTPS 支付回调与第三方支付弹窗、浏览器跳转安全策略、不同主题 Logo/背景是否使用 HTTPS，以及真实账号切换是否泄漏旧状态。

`v0.9.0` 主题包只需像以前一样在 TXBoard「主题管理」中上传；生产环境不会因 GitHub 提交而自动安装。
