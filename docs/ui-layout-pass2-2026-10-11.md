# Luma Theme 第二轮响应式布局精修

依赖：Draft PR #14（主题文字对比度、触控面积与前端 Skills）。本变更叠加在 #14 的独立分支上，不针对未合并的 main 直接改写。

## 问题与解决

1. **长站点名称撑开顶部栏**：`LiveApp.jsx` 原将站点名称作为 Flex 容器的匿名文本节点，无法单独进行省略处理。现在包裹 `.brand-title`，保持站点 Logo、导航和右侧操作按钮的独立弹性布局，文本只在可用空间内截断。完整名称保存在 title 属性。
2. **客户端列表的移动端规则失效**：桌面为 `display:flex`，`responsive.css` 却先后两次通过 `grid-template-columns` 尝试修改布局。这些属性不会让 Flex 容器变成网格。现在在小屏断点真正切换为 Grid，并用 `repeat(auto-fit, minmax(108px, 1fr))` 自适应列数。
3. **重复覆盖的 CSS**：移除了同一 `@media (max-width:720px)` 内的三段客户端固定列宽规则、两段旧两列设置、四段已被最终单列覆盖的商店网格规则；保留最终商店单列效果和 14px 间距。

4. **平板端导航遮挡**：将桌面站点标题容器最多限制为 360px，同时在 721–1100px 范围内按可用宽度进一步缩小，使默认的全部主导航项目无需横向滚动即可看到。320px 手机端客户端列表保持至少两列，减少页面纵向长度。

## 回归验证

- 长站点名称不得挤占右侧按钮，站点名称可由省略号处理。
- 页面整体无水平溢出，客户端项目位于父容器内。
- 720px 以下为自适应 Grid（320px 维持两列），大屏为原始 Flex；检查底部导航响应式切换。

- 后端均用模拟 `/txapi`，不会触发实际支付。
