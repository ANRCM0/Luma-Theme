# Luma Theme — UI/UX 审查与第一轮精修（2026-10-11）

基线：`main` @ `8dc2b28f`，正式 Release `v1.0.2`。

## 本轮采用的参考
- UI/UX Pro Max：以对比度、触控面积、键盘可用性、响应式和暗色主题为优先检查项。
- Web Interface Guidelines：布局、可操作性、可读性与一致性。
- Vercel React Best Practices：避免无依据的组件重写与性能退化。
- 仓库添加了三个**原创、项目特定**的 agent SKILL.md（UI audit / responsive QA / React performance）。它们并非上述外部 Skill 的整份拷贝，也不自动安装到任何人的全局 AI 环境。

## 静态审查结果与代码调整
1. 浅色模式原有 `--color-accent: #2a9ea8` 在白底约为 **3.20:1**；辅助文本 `#778892` 为 **3.67:1**；更浅的 `#9aa9b0` 为 **2.42:1**。这类普通小字不满足 WCAG AA 建议的 4.5:1。
2. 将浅色主色调整为同色系更深的 `#147581`，hover 到 `#0e6470`，辅助文字调整为 `#5a6c76` 和 `#61727d`；保留原有浅青背景、圆角体系、暗色模式和主要视觉布局。
3. 顶部图标按钮原为 35×35px，手机为 38×38px；订阅链接图标按钮为 36px，平台切换按钮高度为 32px。统一相关控件至少 44px；同样将主要按钮的高度从 42px 调为 44px。
4. 390px 以下底部导航标签原降为 9px，调整为 11px；其他手机宽度也统一 11px，优先保证可读性。
5. 新增 Node 颜色对比度单测、Playwright 手机触控区域与页宽测试。**这些是自动检查，不替代人工截图巡检。**
